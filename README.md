AlgoQuest — desain awal dipertahankan, dengan tambahan Simulasi Algoritma Sorting bertahap.

Buka index.html di browser. Bagian Simulasi Algoritma Sorting memungkinkan siswa memilih Bubble Sort, Selection Sort, atau Insertion Sort, memilih ascending/descending, memasukkan angka, lalu menggunakan tombol Sebelumnya/Langkah berikutnya untuk mempelajari proses. Bagian Sorting Arena dan Game 1–3 tetap dipisah di bawah/halaman navigasi untuk dimainkan setelah simulasi.

Prototipe berjalan lokal dan belum memiliki server/database.
