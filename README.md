AlgoQuest — Revisi Lengkap

Perubahan:
1. Simulasi algoritma Sorting menampilkan tabel Riwayat Langkah (Langkah, Aktivitas, Keadaan data) untuk Bubble Sort, Selection Sort, dan Insertion Sort. Tabel mengikuti algoritma, data, dan urutan yang dipilih.
2. Kuis evaluasi terdiri dari 10 soal dengan 5 pilihan A–E.
3. Tombol Periksa 10 jawaban nonaktif sampai seluruh soal dijawab.
4. Setelah submit, jawaban dikunci, skor dan penanda benar/salah ditampilkan. Tidak ada tombol ulangi.
5. Hasil kuis dapat dicetak/disimpan sebagai PDF, dan ringkasan jawaban dapat dibuka ke WhatsApp guru.
6. PDF LKPD menampilkan pertanyaan lengkap sesuai website dan jawaban siswa. Tanggal serta paraf dihilangkan.

Cara menggunakan PDF: pilih Cetak/Simpan PDF, lalu pada dialog browser pilih Save as PDF. WhatsApp tidak dapat melampirkan file secara otomatis; siswa melampirkan PDF secara manual.

Catatan: prototipe lokal, data tidak tersinkron ke server.
