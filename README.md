# AlgoQuest — Sorting Quest
Prototipe website pembelajaran Informatika kelas X.

Fitur:
- Mode siswa saja.
- Materi lebih lengkap tentang sorting, ascending/descending, elemen, perbandingan, swap, Bubble Sort, Selection Sort, Insertion Sort, contoh Bubble Sort, istilah, dan kesalahan umum.
- Simulasi manual drag-and-drop dengan sentuhan di ponsel atau mouse di komputer.
- Game berjenjang: Game 1 membuka Game 2; Game 2 membuka Game 3.
- Kuis dengan skor dan umpan balik.
- LKPD dapat dicetak/disimpan sebagai PDF melalui dialog browser.
- Tombol WhatsApp membuka chat dengan pesan pengantar. Siswa perlu melampirkan PDF secara manual.

Cara menggunakan:
1. Buka index.html dengan browser modern.
2. Untuk PDF, isi LKPD, centang konfirmasi, lalu pilih tombol cetak dan pilih “Simpan sebagai PDF”.
3. Untuk WhatsApp, masukkan nomor guru dengan format internasional, misalnya 62812xxxxxxx. Lampirkan PDF secara manual di WhatsApp.

Batasan:
Ini prototipe frontend lokal. Jawaban dan progres tidak tersimpan ke database/server, tidak ada akun siswa, dan guru tidak menerima tugas otomatis. Kemajuan pada halaman dapat hilang saat halaman ditutup. Uji interaksi sentuh pada perangkat siswa sebelum digunakan di kelas.
