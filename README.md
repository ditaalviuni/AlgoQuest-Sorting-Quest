# AlgoQuest — Final Revisi
- LKPD PDF menampilkan teks pertanyaan lengkap yang sama dengan halaman LKPD dan jawaban siswa; tanggal serta paraf siswa dihapus.
- Sorting Arena dan Game 2 mendukung drag-and-drop bebas tanpa aturan pembatas gerakan.
- Game 2 dipoles menjadi misi Portal Kristal.
- Kuis: 10 soal, pilihan A–E, jawaban benar/salah baru terlihat setelah submit, submit hanya satu kali per sesi dan kuis dikunci sesudah submit.
- Hasil kuis dapat dicetak/disimpan sebagai PDF berisi soal, jawaban siswa, kunci jawaban, dan status benar/salah.

Untuk PDF, isi nama dan kelas pada LKPD, lalu pilih cetak/simpan PDF. Hasil kuis juga memakai dialog cetak browser; pilih “Save as PDF”. File tersimpan pada perangkat setelah pengguna memilih lokasi simpan.

Catatan: prototipe lokal; belum ada database/server. Uji di browser ponsel sebelum digunakan siswa.
